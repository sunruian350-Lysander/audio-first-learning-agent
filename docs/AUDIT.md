## 当前完成程度

**已实现并可自动化检查：** 真实来源定位、课程结构验证、稳定单元 ID 和课程内容散列、应用主线状态机、独立讨论锚点、逐句播放确认协议、连接归属与 CAS 版本保护、迟到响应隔离、SQLite 持久化与事件、断线/重启恢复、文字/朗读降级、Notebook 导出。测试与实际界面检查结果以 [VALIDATION](VALIDATION.md) 为准。

**部分实现、仍需实际验证：** 真实模型课程生成、口述自然度、公式和补充解释的忠实度、Realtime 音频链路、自然说话打断、连续多轮讨论、准确口头恢复、移动网络条件与低操作负担。适配器代码存在、模拟通过并不等于真实服务已验证。

**尚未实现：** 学习者跨会话知识记忆、掌握度追踪、自适应课程、主动理解诊断、实践自动反馈、隔离代码执行、OCR、录音/视频导入、后台/锁屏保证、多用户与云同步。本次没有服务密钥，未产生真实模型或语音调用验证记录。

## 与产品原则的差距与修正

- **对话原生与语音入口：** 旧流程需要点击打断和文字输入。新增实时语音路径，保留文字降级；真实免看屏幕路径待实测。后续多模态衔接与自适应教学仍需实现。
- **课程连续性：** 旧模型问答能保存句子位置，但没有独立实时讨论状态。新增教学状态机、锚点、输出 ID、版本与连接归属，使长讨论不能自行推进课程。
- **可靠检查点：** 不以“发给模型”或“生成完毕”认定听完；结合输出缓冲完成和浏览器播放条件确认。设备真实出声与理解仍需额外证据。
- **模型可替换：** 沿用文本接口，新增语音接口；首版只实现一个语音供应商，避免一次集成两套链路。
- **证据驱动：** 保留原文与改写边界，新增教学元数据和事件；不将播放完成显示为掌握。延迟只有观测字段，无未经测量的达标数字。
- **渐进复杂度：** 不引入多 Agent 对话框架或向量基础设施，先做短课程闭环。实践导出保留，优先完成实时语音与主线恢复。

## 达到 P0 的最短实现路径

当前代码已具备真实服务接入点。下一步需要明确启用供应商服务，导入短教材，验证实际音频路径与内容质量，按 [ROADMAP](ROADMAP.md) 的 12 项用户体验要求及异常场景逐项记录。遇到句间等待、识别误触发或供应商事件差异时，优先修复影响连续性的具体问题。真实联调通过后才能把 P0 标为完成。
