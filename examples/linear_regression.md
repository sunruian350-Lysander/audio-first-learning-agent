# 从直觉理解线性回归

线性回归用一条直线描述输入 x 和输出 y 的关系。预测值等于 w 乘以 x 加上 b。w 是斜率，b 是截距。模型参数需要从样本中学习。

# 用均方误差衡量偏差

先计算预测值与真实值的差，再平方，最后对所有样本取平均，就得到均方误差。平方使正负误差不会抵消，也会放大较大的误差。训练误差小不保证对新样本预测准确。

# 梯度下降让误差减小

梯度下降沿损失梯度的反方向更新参数。学习率决定每次走多远，过大可能发散，过小会收敛缓慢。固定截距 b 等于零时，w 的梯度是所有样本中二乘以预测误差再乘以 x 的平均值。

# 用 Python 验证

使用输入一、二、三，对应输出二、四、六。固定 b 等于零，从 w 等于零出发，学习率取零点一。计算一次梯度，更新 w，再比较更新前后的均方误差。
